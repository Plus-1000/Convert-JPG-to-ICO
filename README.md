# Convert-JPG-to-ICO
Convert JPG images into ICO icons

If you don’t have a suitable shortcut icon, you can design one in PPT and convert it. Online tools work, but using Python is simpler and safer for personal use.

<br/>
<br/>
## How it works
1. Create the icon image in PPT or other software.
  <p align="center" height="180">
  <img src=https://github.com/Plus-1000/Convert-JPG-to-ICO/blob/main/pic/Design%20icon%20with%20PPT.jpg length="100">
  </p>

 
<br/>

2. Save it as JPG.
<p align="center">
<img src=https://github.com/Plus-1000/Convert-JPG-to-ICO/blob/main/pic/Save%20as%20JPG.jpg length="150">
</p>

<br/>
3. Open the app → choose icon size → drag & drop JPG → ICO file is generated in the same folder.

<br/>
<p align="center">
<img src=https://github.com/Plus-1000/Convert-JPG-to-ICO/blob/main/pic/Run%20app.jpg length="100">
</p>

<br/>
4. Icon file converted.
